# So

本项目用于托管自动化任务的核心动态二进制库（通过 GitHub Releases 独立发放）及各模块运行配置说明。

---

## 📌 运行环境与 Python 版本要求

由于二进制动态库（`.so`）采用 CPython 原生 C-API 编译构建，对运行时的 Python 主次版本有严格的二进制接口（ABI）依赖：

- **最低支持版本**：**Python 3.10**（支持 Python 3.10.x 及以上）
- **推荐运行版本**：**Python 3.11**（主流 Linux 容器镜像推荐标准版本）
- **不支持版本**：**Python 3.9 及以下版本**（因底层 C-API 结构不兼容，旧版环境强行加载将触发段错误或无法识别）

> 💡 **版本自查**：可在系统终端或调度面板环境中执行 `python3 --version` 查看当前版本。若版本低于 3.10，建议更新拉取最新版运行环境镜像。

---

## 📦 动态库 Release 发放说明

各项目所需的预编译原生 Linux 二进制动态库均统一托管在 **[GitHub Releases](https://github.com/czy13724/So/releases)** 中，代码仓库仅存放配置说明，不存储大体积二进制文件，便于按需自动拉取。

各版本二进制动态库均针对平台架构（x86_64 / aarch64）以及主流 Python 版本（Python 3.11 / Python 3.10）分别提供精准编译包，调度脚本将根据当前运行环境自适应精准加载。
