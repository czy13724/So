# So

本项目用于托管自动化任务的核心动态二进制库（通过 GitHub Releases 独立发放）。

---

## 📌 运行环境要求

各项目核心动态库采用 CPython 原生 C-API 深度编译构建，运行环境要求如下：

- **最低运行环境**：**Python 3.11 及以上版本**（支持主流现代化 Linux 运行环境及各类容器）。
- **硬件架构支持**：支持主流 64 位平台（`x86_64` / `amd64` 与 `aarch64` / `arm64`）。

---

## 📦 二进制库获取说明

各项目的原生 Linux 二进制动态库均统一发布在 **[GitHub Releases](https://github.com/czy13724/So/releases)** 资产中。

- 仓库中不存储任何二进制实体文件，亦不展示内部动态库文件名与路径；
- 调度程序在运行或更新时，将根据宿主机的硬件环境自动从 Release 匹配并拉取对应的核心库，全流程自动完成，无需手动配置。
