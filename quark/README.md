# ⚡ 夸克任务

你知道是干什么的吗就下载？

---

## 📌 运行环境与 Python 版本要求

- **最低支持版本**：**Python 3.10**
- **推荐运行版本**：**Python 3.11**（推荐直接使用最新的容器运行环境）
- **不支持版本**：**Python 3.9 及更早版本**（ABI 结构不匹配，无法加载二进制库）

---

## ⚙️ 环境变量配置

在您的面板或运行环境中配置以下环境变量：

| 变量名 | 必填 | 示例 / 说明 |
| :--- | :---: | :--- |
| **`QUARK_SIGN`** | **是** | **自建算签服务地址**，如：`http://你的服务器IP:6781` |
| **`QUARK_COOKIE`** | **是** | **夸克账号凭据**（含 `kps`），多账号换行或用 `&` 分隔 |
| **`QUARK_GITHUB_REPO`** | 否 | `czy13724/So`（用于自动同步核心库） |
| **`QUARK_RELEASE_TAG`** | 否 | `latest`（核心库 Release 版本标签） |

---

## 📦 核心动态库 Release 下载说明

夸克核心动态库通过 **[GitHub Releases](https://github.com/czy13724/So/releases)** 发放，运行脚本将根据系统架构与当前 Python 版本自动精准匹配并拉取：

| 架构 / 文件名 | 适用平台与环境 |
| :--- | :--- |
| **`quark_core_py311_x86_64.so`** | Linux x86_64 / amd64 + **Python 3.11** |
| **`quark_core_py311_aarch64.so`** | Linux aarch64 / arm64 + **Python 3.11** |
| **`quark_core_py310_x86_64.so`** | Linux x86_64 / amd64 + **Python 3.10** |
| **`quark_core_py310_aarch64.so`** | Linux aarch64 / arm64 + **Python 3.10** |
| **`quark_core_x86_64.so`** | 64 位 Intel/AMD 通用默认库（基于 Python 3.11 构建） |
| **`quark_core_aarch64.so`** | 64 位 ARM 通用默认库（基于 Python 3.11 构建） |
| **`quark_core_linux_all.zip`** | 全版本、全架构二进制库压缩合集 |
